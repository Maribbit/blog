## Project Definition

Maribbit's Blog 3D | 海兔的 3D 博客

This project is Maribbit's personal blog, exploring the integration of 3D elements into front-end AI-driven web development.

## Technologies Used

- **Astro**: This is the framework for building the blog. I used React, Vue, and other frameworks before, but I prefer vanilla HTML, CSS, and JavaScript when AI is involved, and I need a framework to provide HMR and modularity. Astro is currently the only choice that meets my needs.
